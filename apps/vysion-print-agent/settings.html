Vysion Print Agent

Geen installer? Open op deze pc (geen Google nodig):
vysionhoreca.com/download/print-agent-windows
Of technische release: GitHub — Vysion Print Agent (Windows)

Kies de bonprinter die Windows al ziet (USB/Ethernet maakt niet uit). De kassa stuurt bonnen naar http://127.0.0.1:9742/print op deze pc.

Epson- en Star-kassa’s: laat Epson / Star staan. Alleen op Chinese TD80 het tweede type kiezen. Verkeerde keuze = boze klanten.

Alleen aanzetten als iPads in Safari printen naar het IP van deze pc. Windows-firewall moet poort 9742 op privénetwerk toestaan.

Opgeslagen! Kassa opent automatisch.
